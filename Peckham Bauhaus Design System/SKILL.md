If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key facts:
- Bauhaus-inspired: primary red/blue/yellow on warm paper, near-black ink.
- Type: Jost (900 uppercase display), JetBrains Mono (labels/code).
- Signatures: heavy 2–4px ink borders, hard no-blur offset shadows, sharp corners, scattered geometric shapes, numbered sections.
- Link `styles.css` for all tokens. Components live under `components/`; a full portfolio UI kit is in `ui_kits/portfolio/`.
- No real logo — render the wordmark "JOEL PECKHAM" in type with a colored dot.
