**Button** — Bauhaus block button with a hard offset shadow that presses flush on click. Use for primary/secondary actions.

```jsx
<Button variant="red" size="lg">View Work →</Button>
<Button variant="outline">Read more</Button>
```

Variants: `primary` (ink), `red`, `blue`, `yellow`, `outline`. Sizes: `sm` | `md` | `lg`. Set `as="a"` + `href` for links, `block` for full-width. Labels render uppercase mono automatically.
