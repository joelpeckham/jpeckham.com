**Shape** — decorative Bauhaus geometric element. Scatter behind or beside content for the brand's graphic energy.

```jsx
<Shape type="circle" color="var(--yellow)" size={160} />
<Shape type="half" color="var(--blue)" size={200} />
```

Types: `circle`, `square`, `bar`, `half`, `quarter`, `ring`, `triangle`. Decorative only (aria-hidden).
